# Фінзвітність ОККО: від сирих даних до таблиці для аналізу

Компанії: ТОВ «ОККО-ДРАЙВ» (20122395) і АТ «Концерн Галнафтогаз» (31729918), роки 2021–2025.

## Як запустити

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # один раз
.venv/bin/python run_all.py                                          # усі чотири кроки
```

Кожен крок можна запустити й окремо, наприклад `.venv/bin/python step3_excel.py`. Так зручно,
коли ви змінили лише тексти в `reference/`: повільний крок 1 повторювати не треба.

## Пайплайн

```
raw_data/                 (Держстат 2022, Держстат 2025, Опендатабот)
   │
   ▼  крок 1: step1_extract.py
data/1_extracted/         (лише звіти ОККО: оригінали, reports.csv, fields.csv, opendatabot_summary.csv)
   │
   ▼  крок 2: step2_values.py
data/2_values.csv         (одне число на рядок + звідки воно)
   │
   ├─► крок 3: step3_excel.py   ─► output/ОККО_фінзвітність_2021-2025.xlsx   (повна, обидві компанії)
   └─► крок 4: step4_kursova.py ─► output/OKKO_kursova_2021-2025.xlsx        (для курсової, ОККО-ДРАЙВ)
                 ▲
       reference/ (назви рядків, показники, тексти)
```

| Крок | Що робить | Результат |
|---|---|---|
| 1. `step1_extract.py` | Переглядає архіви Держстату, де лежать звіти всіх підприємств, і бере лише звіти ОККО (за ЄДРПОУ в назві файлу). Вирізає XML з підписаних КЕП файлів. Перекладає xlsx з Опендатаботу в ті самі назви полів, що й у XML. | `data/1_extracted/originals/`: оригінали звітів.<br>`reports.csv`: перелік звітів.<br>`fields.csv`: усі поля всіх звітів. |
| 2. `step2_values.py` | Перетворює поля (A1300, B1300…) на «рядок 1300, рік N». Бере останнє подання, якщо звіт уточнювали. Обирає найкраще джерело для кожного року: звітна колонка → порівняльна колонка наступного звіту → сайт Опендатаботу → ручні дані. | `data/2_values.csv`: одне число на рядок, з джерелом, і всі кандидати з позначкою «обрано». |
| 3. `step3_excel.py` | Повна таблиця по обох компаніях: аркуші форм 1–4, показники-формули, огляд, розбіжності, джерела. | `output/ОККО_фінзвітність_2021-2025.xlsx` |
| 4. `step4_kursova.py` | Таблиця для курсової: лише ОККО-ДРАЙВ (Ф1, Ф2, ключові рядки Ф3), 24 показники, таблиця Опендатабота, довідка про Галнафтогаз. | `output/OKKO_kursova_2021-2025.xlsx` |

Кроки 3 і 4 незалежні: обидва читають `data/2_values.csv`. Якщо повна таблиця не потрібна,
видаліть `step3_excel.py` (і рядок про нього в `run_all.py`), а крок 4 працюватиме далі.
Спільні для них стилі, формули й типові аркуші лежать в `excel_common.py`.

Спільні налаштування (компанії, роки, шляхи) лежать у `common.py`.

## Сирі дані (`raw_data/`)

| Папка | Що там |
|---|---|
| `forms2022/` | Держстат: форми 1–4 за 2022 р. (з порівняльними даними 2021 р.), звіти всіх підприємств |
| `fin_zvit_2025_ric_…/` | Держстат: архіви форм за 2025 р. (з даними 2024 р.) |
| `opendatabot/2026-11-*.xlsx` | Опендатабот: Ф1 і Ф2 ОККО-ДРАЙВ за 2023 р. (з даними 2022 р.) |
| `opendatabot/фінпоказники_<компанія>_<ЄДРПОУ>.png` | скріншоти таблиці «Фінансові показники» з opendatabot.ua |
| `opendatabot/фінпоказники_<компанія>_<ЄДРПОУ>.csv` | ті самі таблиці, переписані зі скріншотів (суми в гривнях) |

Таблиці з сайту — це підсумки агрегатора, а не оригінальні форми. У рядки форм із них беруться
лише дохід (р.2000), чистий прибуток або збиток (р.2350/2355) і активи (р.1300 = р.1900), і лише
за ті роки, де форм звітності немає (зараз це Галнафтогаз 2023). В Excel такі клітинки мають жовте тло.
Решта показників (зарплата, працівники…) — на аркуші «Опендатабот». Якщо сайт і форма
дають різні числа, це видно на аркуші «Розбіжності».

## Що можна правити без коду (`reference/`)

| Файл | Що в ньому |
|---|---|
| `row_names.csv` | назви статей для кодів рядків |
| `notes.csv` | примітки до рядків (стовпець «Примітка») |
| `indicators.csv` | аналітичні показники. Формула пишеться як `Ф2[2090] / Ф2[2000]`, попередній рік — `Ф2[2000](t-1)`. Колонка «у курсовій» = «так» означає, що показник іде в таблицю кроку 4 |
| `kursova_texts.csv` | тексти таблиці для курсової: аркуші «Огляд», «Джерела», примітка «Довідки_ГНГ» |
| `manual_values.csv` | числа, внесені вручну (зараз порожній); у таблиці вони на жовтому тлі |
| `overview.csv`, `sources.csv` | тексти аркушів «Огляд» і «Джерела» |

## Позначення в Excel

- Сині цифри — дані звітності.
- Чорні — формули.
- Жовта заливка — не з оригінальної форми (сайт Опендатаботу або ручні дані).
- «н/д» — даних немає.
